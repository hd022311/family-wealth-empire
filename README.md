# 家族財富帝國

> 最新範圍基準：見 [STATUS.md](STATUS.md) 與 [FEATURE_BACKLOG.md](FEATURE_BACKLOG.md)。目前只收斂V0.1公開部署與核心穩定；舊文件的實驗批次編號不代表正式里程碑完成。

繁體中文 2D 等角家族財富經營遊戲。Vite + TypeScript + React + Phaser。手機、平板與桌面瀏覽器皆可操作；每次 5–15 分鐘，長期累積多代進度。**所有行情均為虛構資料，未連接任何真實行情。**

## 執行及預覽
Node.js 22 以上（目前使用 24）。
```sh
npm ci
npm run dev -- --host 0.0.0.0
```
開啟 5173 埠。正式版本：`npm run build`，再 `npm run preview -- --host 0.0.0.0`（4173 埠）。正式版首次連線完成快取後，支援離線重新開啟；開發伺服器不提供離線快取。若瀏覽器禁止 Service Worker，只能在已載入頁面繼續離線遊玩。切換到新版需關閉舊分頁再重開。

```sh
npm test             # 模擬、存檔、排行榜契約、PostgreSQL 權限測試
npm run test:e2e     # 建置後，桌面、平板與手機 Chromium 煙霧測試
```
瀏覽器測試預設 `/usr/bin/chromium`，可透過 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 改路徑；需另備相容 Chromium。資料庫測試使用嵌入式 PostgreSQL（PGlite），**不等同已連接正式 Supabase**。

## 已可玩的核心
- 點選等角城市建築，或使用房產列表；銀行開啟帳本及還貸。包含程序建築、樹木及行人。
- 劇情模式 30 歲、自由模式自訂年齡；經典存檔保留 25 歲開局。每遊戲月 15 秒；可暫停或 1/4/12 倍速。到 85 歲一生約 3 小時活躍遊玩，分次累計，不要求連續完成。分頁隱藏、失去焦點或開啟存檔/排行榜面板時停止推進。
- 收入、生活費、租金、房貸利息、維護費、資產負債及淨資產帳本；新模式薪資依職涯，經典存檔維持舊規則。房屋頭款三成、貸款七成，年息 2.5%，可出租、按月收租、還本金及賣出（費用 2%）。
- 虛構股票買賣及月度景氣波動；家庭成長、退休、85 歲死亡與下一代選擇。
- 0.3 接班：成年下一代接續自己的個人帳戶，原家主資產、房貸及股票進獨立遺產保管。法源、稅務與分割未核實前不均分、不自動出售或加錢；保留上一代快照、家族人物、記憶與爭議。
- 多個獨立本機家族、每次狀態變更自動儲存、手動存讀檔、舊單一存檔遷移。遊戲內記事保留最近 40 條，各代快照保存其結束時紀錄。
- 沒有離線年齡、死亡、利息、生活費或股價推進。本階段虛構市場離線進展上限為零；回歸時顯示離開時數及凍結政策。沒有每天登入的懲罰。

## 訪客 → 會員 → 跨裝置
未設定雲端也可完整試玩。「家族存檔 / 會員」可建立及切換家族，切換時暫停遊戲。本機存檔只存在當前瀏覽器，清除網站資料即遺失。

### Supabase 設定（選用；目前未驗證遠端連線）
1. 建立自己的 Supabase 專案；在 SQL Editor 依序執行 `supabase/migrations/202610230001_family_saves.sql` 及 `202610230002_rankings_spec.sql`。兩份遷移只執行一次；第二份只是排名結構，預設沒有開放排名服務。
2. 複製 `.env.example` 為 `.env.local`，在專案 API 設定找到 Project URL 及 **publishable key**，填入 `VITE_SUPABASE_URL`、`VITE_SUPABASE_PUBLISHABLE_KEY`。這是可公開的瀏覽器金鑰；**絕不可放 service_role、資料庫密碼或私鑰**。
   若雲端環境限制網路目的地，另將該專案的實際主機名稱加入允許清單（例如你的 project-ref.supabase.co）；不需要開放所有網域。
3. Supabase Authentication 啟用 Email provider；在 URL Configuration 設定你實際使用的網站網址與允許的驗證回跳網址。開發時使用實際的 Vite 網址，正式部署使用 HTTPS。
4. 重啟 Vite（或重新建置）。在會員面板註冊、依設定驗證信箱、登入。
5. 按「同步所有家族」明確同意上傳訪客進度。登入會下載既有雲端家族；切換至該家族接續。已綁定目前帳號的家族每 30 秒檢查同步，恢復網路時也會檢查。失敗保留本機資料，訊息顯示錯誤，不假報成功。
6. 兩個裝置同時修改時，不合併金錢與時間、不直接覆寫；先保留本機為新家族，再選用雲端版本。副本需明確按同步才上傳。另一帳號的本機家族不自動上傳到目前帳號。

每次雲端寫入以 expected revision 原子比對；RLS 隔離使用者，禁止客戶端直接更新表格。但個人沙盒快照是 **unverified_sandbox**：這是同步一致性與帳戶隔離，不是財務防作弊。正式競賽須先實作伺服器權威命令、財務帳本與驗證器。

公開裝置注意：登出不會清除本機家族；同一瀏覽器使用者仍可看到這些本機進度。需要隱私時，請登出後清除網站資料。

## 家族人性與法律（0.3）
開局可選白手起家／富裕／一般家庭；可點人物查看獨立資產、關係圖與自主決策理由。新增探望、援助、借款紀錄、照顧承諾、父親重大疾病、手足負擔及祖厝協商，具有實際費用、時間、健康、工作及家族記憶變化。

固定「⚖ 台灣法律」入口提供主題、關鍵字及條號查詢。**官方法源因環境 CONNECT 403 尚未完成核對，正式法律份額、特留分與稅額不會顯示虛構數字；正式分產尚未啟用。**規則演算法使用獨立測試來源驗證，不代表現行法審核通過。請見 [家庭與法律操作](FAMILY_LAW.md)、[法源核對清單](legal-review/VERIFICATION.md)、[任務與測試計畫](TASKS.md)。

## 0.4：雙模式與小型開放世界
首次開啟顯示模式首頁；既有家族直接續玩。「首頁 / 新人生」隨時另開獨立家族，不覆蓋原存檔。劇情模式從 30 歲開始，已有職涯、配偶、兩名子女、父母及兩名手足，父母資產獨立；自由模式可設定姓名、家族名稱、18–60 歲、背景、配偶及 0–3 名子女。舊家族的收入與財產維持原樣。

驗收步驟：
1. 選劇情模式，城市點建築或下方「城市場所」前往公司；空白可通行地面可點選移動，拖曳平移、滾輪或雙指縮放。
2. 自由模式可到公司、商店、銀行或社區中心應徵四種職涯；金融與接案需專業 12，可付費進修。新模式預設時間暫停，按 12× 約每 1.25 秒一個月，領取薪資；瀏覽器須在前景。
3. 按市民卡上的位置前往並交流；領過薪且認識人物後，到社區中心投入 $30,000 啟動服務工作室。每月收入 0–9,000、支出 2,000，均為虛構遊戲數值。
4. 購房、股票交易仍使用既有介面；住宅與公園可進入家庭互動，探望父母、協商照顧。六歲以上子女可在社區中心接受能力培養。
5. 回首頁另開自由模式，然後從「家族存檔 / 會員」接續原劇情家族；重新載入確認模式、人物、工作及記憶保存。

新增八名有工作、家庭責任、財務、個性、能力與目標的市民，加上家族約 11–17 位存活 NPC（依開局設定）。市民即使未交流也按活躍遊戲月份領薪、支出、進修及轉職。場所輪替是月度生活排程，非完整逐時 AI。地面移動使用格網尋路，場所按鈕為快速前往，移動動畫不計算財務。

劇情五階段由家族狀態推導，第一章提供非強制目標，不自動觸發疾病或分產；後四章的專屬內容尚待擴充。企業人才系統目前僅能力培養與接班保留能力，尚無招聘團隊與完整公司治理。市民家庭目前為責任描述，未建立每位市民配偶子女的完整獨立人物網路。

存檔內層升至 v3，可遷移 v1/v2；多家族與雲端封套維持 v1，沿用 UUID、CAS 衝突及 RLS 架構。新模式接班保留世界歷史、原家族與爭議；新家主不自動取得前代職位、人脈或工作室權利。待法律驗證的遺產繼續保管，不產生虛構分配。

**外部服務狀態：未驗證正式 Supabase 連線，未取得可靠官方法律正文與施行版本。** 設定 `.env.example` 所列 Supabase URL／公開金鑰後需另行實測；法定繼承、特留分及年度稅務仍須官方來源核實與法律專業審核。

## 0.5：劇情《兩間房子的承諾》第一、二章
新開劇情有父母兩間房子：自住房與出租房，位於可互動城市建築，收入／支出只進各自屋主帳。主角從自己的家庭與工作出發；兩名手足各有工作、配偶、子女、負債、責任與目標。新增月度時間安排、健檢與照顧追蹤、手足自主分工、修繕停租、任務、近況與長期記憶。穩定照顧可改善健康並結案，之後照常工作、投資與經營。

請看 [第一、二章操作與驗收](STORY_PROMISE.md)。新玩家首頁直接開始；已有玩家從「首頁 / 新人生」另開本主線。舊劇情與自由模式不被轉換，v1–v3 → v4 只遷移格式，保留原資產與歷史，首次保存遷移前備份舊庫。後四章只完成事件框架；沒有正式遺囑分配、保險理賠或稅務規則。法律資料仍待官方核實與專業審核。

可攜試玩檔：`npm run package:demo` 產生 `artifacts/family-wealth-empire-demo.html`（全部程式／素材內嵌，關閉雲端及 Service Worker），同時輸出 `dist/standalone.html` 供靜態主機使用。若你的瀏覽器允許開啟本機 HTML，可下載開啟；本環境管理政策禁止 file://，不宣稱直接開檔已通過此環境驗證。可把 artifacts 交給靜態伺服器：`python3 -m http.server 4173 --directory artifacts`，再由該機器瀏覽器開啟對應 HTML。

**目前環境內的 4173 埠不是公開遊玩網址。** 對外預覽服務實際被網路代理 CONNECT 403 阻擋；所需網域已保存於環境設定草稿，尚待套用並重新驗證。沒有宣稱外部部署成功，也不提供無法從外部連入的 loopback 網址冒充交付。

預覽連線補充：環境重新連接後原網域已可送出請求，但 SSH 預覽連線未建立；新增 `service.tunnelmole.com`、`*.tunnelmole.net` 的 HTTPS／WebSocket 需求已另存草稿，第一次連線仍為 403，尚未產生可交付的公開網址。
