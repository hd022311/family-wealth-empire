## 素材與演出界線

沿用prologue的父母/怡君候選圖集、餐桌客廳/醫院候選背景，與dual-stage三手足圖集。皆為既有候選素材，不是正式動畫美術。

手足可使用既有一致臉部圖層作短暫表情混合與非同步眼部眨動；無全身晃動、嘴型/骨架/配音。父母與怡君缺少多表情/視線圖層，目前仍是單姿勢候選立繪；整理櫃子、手機照片、湯碗、手套等以心聲和台詞傳達，尚非實際道具動畫。既有鏡頭透過獨立橫直臉部定位呈現，不裁切整張概念圖冒充動畫。
