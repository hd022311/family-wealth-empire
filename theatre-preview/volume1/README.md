# 《兩間房子的承諾》第一卷整合版

整合版入口：https://hd022311.github.io/family-wealth-empire/theatre-preview/volume1/

部署與外部HTTPS結果以GitHub Actions為準，實體手機仍待玩家驗收。

此版本將既有82秒前言與原本六次選擇、八種敘事結局接在同一個閱讀引擎；沒有新增劇情選擇、正式法律計算或經營模式功能。

## 使用

從儲存庫根目錄執行 `python3 -m http.server 4191`，開啟 `http://localhost:4191/theatre-preview/volume1/`。

新故事由冷開場開始，經2026年家庭日常與父親出院，直接進入第一個照顧選擇；舊版兩段INTRO與首次照顧前導不再疊播。前言可手動閱讀，也可選擇82秒自動播放；其後逐段手動閱讀。

選取 A／B／C 後須確認；費用與後果提示沿用原文。略過只跨越已讀內容，停在未讀、任何重要選擇與結局，不會自動代選。

選單提供三種字級、情緒開關、減少動態、對話回顧、前言重看、結局收藏、兩輪比較與未完成閱讀備份。台灣法律可隨時查詢。

## 存檔相容性

- 新版使用 `fwe.theatre.volume1.reading.v2`，schema 2；原 `fwe.theatre.volume1.reading.v1` 僅讀取，不修改或刪除。
- 首次載入新版且尚無v2時，驗證並複製原v1的目前位置、六次選擇、全部結局收藏、原始已讀鍵、字級與動態設定。
- 舊周目以 `origin: legacy` 保留原本flow/cursor/line，從原位置續讀，不強迫插入新前言。下一輪改用整合flow。
- 原逐字偏好仍保存在v1。新版採電影式整句字幕，不另行改寫舊設定。
- 獨立前言讀檔只匯入已讀段落及適用偏好，不匯入其試選的照顧方案，不產生支出。
- 前言自動播放時，暫停／切到背景／離頁會保存本句秒數；重新整理回到入口按「繼續閱讀」，從原句暫停接續。
- 前言重看只更新已讀標記，不改active的選擇、位置、支出或結局。重看中重新整理回到原故事位置，而非另做一次照顧選擇。
- 開新周目保留所有已完成紀錄；未完進度自動另存閱讀備份，可由選單恢復。
- 新資料無法驗證時不回退覆蓋；壞檔保留，暫時觀看不寫入。
- 每次寫入前比對本頁上次讀到的原始紀錄，偵測到另一分頁更新即停止寫入，不覆蓋較新資料。沒有自動合併兩頁內容。
- 新版首次遷移後，舊入口後續的新進度不自動與v2合併。兩個入口的原始資料皆保留。
- 本機容量不足時顯示未保存提示，不刪除舊紀錄；沒有Supabase／雲端同步或跨瀏覽器同步。

## 視覺與素材

共用既有PrologueRenderer及人物、背景素材。前言保留原群像與橫直構圖；後續依場景切換客廳、醫院、住宅及原有事務所候選背景。旁白使用空景，避免父母死亡後在反應鏡頭中重新出現。

姓名20px／正文24px基準；100%、125%、150%放大，短高度姓名與字幕同列、長文可展開。六種情緒元件沿用既有測試版本，前言3句啟用憤怒／悲傷／堅定，其餘不強迫加動畫。系統與手動減少動態優先。

所有人物與背景仍是候選素材，正式動畫美術簽核為0。沒有新增骨架、語音、手持物動作或全套表情。不得將本版稱為已完成正式動畫影集。

## 邊界

`story.mjs`、原法律資料、舊閱讀模組、獨立prologue、dual-stage與人物樣機皆保持原檔案。新入口不是把獨立原型的照顧結果直接帶回正式劇情。

法律、稅務、保險、分產、理賠及裁判效果仍待核實。八種結局是敘事結果，不是法律確定結果；父母財產從未計入玩家生活預備金。
