# 《傳承人生劇場》遊戲設計文件

版本 0.1・2026-10-24（台灣時間）・供美術、閱讀與劇情選型。

這是《家族財富帝國》的第二種**規劃中**體驗：每卷約5–10分鐘的現代台灣家庭互動視覺小說。本次只做第一卷的有限互動原型及規格，沒有整合正式經營模式、沒有改 State v4，也沒有正式法律計算。

## 一句話體驗

你想接住父母，也不想放掉自己的生活。六次選擇，讓同一個家庭以不同方式走到同一張餐桌前；房子不是唯一的答案。

## 產品界線

- 每卷獨立開局、人物對話→重要選擇→短期回應→時間跨越→後續反應→敘事結局→自願閱讀的法律回顧→重玩。
- 不是經營模式的縮小版：沒有月份自動計時、城市點擊經營、股票交易或長期資產模擬。
- 不是金融選擇題：沒有「答對法律就獎勵」；玩家選的是如何生活，法律規則不由選擇分數改寫。
- 照顧、界線、工作、金錢與誤解均有取捨；哥哥的房貸、妹妹的輪班、配偶的家庭責任都可能合理。
- 保險可以討論、評估或不採用；不保證承保、理賠、節稅或最好結局。

## 目標玩家與閱讀節奏

以40歲以上也能輕鬆閱讀為設計基準。桌面內文20px、手機／平板18px，100%／125%／150%放大為20/25/30px或18/22.5/27px；不靠小字塞資訊。

每段通常兩個短句，預設分成2段，桌面約2–4行。小螢幕及放大後允許增加行數與面板捲動，不強迫壓回四行而裁字。一次只呈現對話或決策；每個決策有三個主要選項。具體支出與不確定性放在選項內，不能先扣款再揭露。

第一卷目前有六次決策、22段對話與結局（約29個主要閱讀／決策畫面）；目標5–10分鐘是規劃值，尚未經真實玩家計時驗證。快速點擊可更短，展開全部法律資料會更久，不能以自動化腳本的完成時間宣稱玩家時長。

## UI 與互動

1. **書架／封面**：單一第一卷封面、開始按鈕、預估篇幅及原型標示。其餘卷只在選單裡列為企劃，不做五張活動卡常駐。
2. **對話**：大幅人物＋場景，底部一塊高對比對話區，一個「下一段」。沒有金額儀表板、資源列或人物好感條。
3. **決策**：角色前一畫面先說完，再顯示一個問題與2–3選項；不堆上同一段說明。選項寫出虛構成本及風險。
4. **輔助功能**：右上只有「台灣法律」和「選單」。選單內有字級、已讀對話、本輪事實、結局方向及重開。任一時刻只有一個可關閉視窗，內容可捲動，Escape可關閉，關閉後焦點回到原入口。
5. **結局**：兩段短故事＋三個操作：選擇回顧與法律、重新挑戰、其他結局方向。詳細回顧、法律、日期與其他可能結果都用自願展開，不把結局變成教材長頁。
6. **觸控**：主要目標至少48px；正常按鈕52px。面板不因150%字級遮住關閉／繼續按鈕。對話與決策區可獨立捲動。
7. 不強制音樂、旁白、打字機效果或自動播放；目前無聲音。未使用計時器強迫閱讀或作決定。

## 美術規格與本次資產狀態

- 方向：原創現代台灣2.5D自然光影，暖白、深玉綠、少量陶土色；不使用武俠、戰鬥、幻想金邊或他作遊戲素材。
- 已製作**概念素材**：住宅巷口、客廳、醫院等待區、事務所四景；主角、配偶、父親、母親、哥哥、妹妹六人。
- 場景四格圖／人物六欄圖用CSS定位展示，不代表已完成正式可交付的獨立背景與角色Sprite套件。
- 角色目前各一個基礎表情，沒有正式五表情、眨眼、呼吸、換裝或老化素材；人物跨年未換外觀，這是明確的原型限制。
- 正式製作應逐張拆出角色透明立繪、補齊至少一般／壓力／釋懷表情、修正手部與邊緣，增加手機構圖安全區及壓縮格式；概念圖仍需人工相似性與品質審查。
- 現有原型會在父母死亡後停止其現時對話／登場；結局只以活著的主角出場，不讓過世NPC繼續參與即時協商。

- 未加入帳號、追蹤、抽卡、付費、廣告或真實家庭資料蒐集。

## 法律與故事的五層區分

A. 法律確定規則：本次無 approved 規則，故無確定計算。
B. 已知故事事實：虛構人物、兩棟房屋的原設定屋主、支出與事件日期。
C. 人物反應：條件式寫作，不是法院或主管機關的判斷。
D. 可能法律爭議：遺囑形式、特留分、夫妻財產、契約、分割、稅務等列為待查。
E. 待確認司法結果：不產生勝敗、強制出售、全部凍結或稅額。

人物願意協商，不等於有效協議；遺囑文件存在，不等於本原型已判定有效。故事跨至2029與2031的日期是假設時間，不是對未來法規的預測。
