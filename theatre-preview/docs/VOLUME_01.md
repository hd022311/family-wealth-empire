## 八種結局與判斷順序

依下列順序判斷，先命中的敘事條件成立。這是**敘事路由**，不是法律引擎。八種均可由六次真實選擇走到；所有未決法律事項保留，不以完成結局冒充法律結清。

| 結局 | 條件（以前列優先） | 故事與教育目的 |
|---|---|---|
| E6 誰也沒有先退讓 | D6各自法律途徑 | 停在裁判之前；法律途徑不必然是壞選擇，也不保證勝敗或全部凍結 |
| E7 走到談判桌之前 | D6先釐清，且D5先談兩屋去向 | 承認清冊不足；父母各次遺產、原有所有權與財產鏈須分開確認 |
| E4 照顧者也需要被照顧 | D1親自照顧＋D2先答應全部 | 經濟與照顧負荷累積；付出不自動改寫法定權利，也不是玩家失敗處罰 |
| E5 文件很齊，心事未完 | D3獨立專業協助＋D2非透明預算＋D6先釐清 | 文件準備與關係修復是兩件事；「有文件」仍未等於效力已審核 |
| E3 遲來的一張餐桌 | D6協商，且D2先答應全部或D5先談兩屋 | 先前誤解被承認；願意再談不等於簽成或完成有效分割 |
| E2 兩間房之外的生活 | D1專業照顧＋D2透明預算＋D4保留現金＋D5非搶先分屋＋D6協商 | 保留自己的生活與流動性，不買新保險也可有正向敘事方向 |
| E1 留下可對話的家 | D1分工＋D2透明預算＋D3非僅口頭＋D5非搶先分屋＋D6協商 | 可持續對話是關係成果；不改應繼分、不宣告房屋已到主角名下 |
| E8 把答案留給下一頁 | 其他未命中組合 | 留下事實、界線及待辦；不是下一代自動承接未處理的財產 |

每個結局都有：短故事、六次選擇回顧、支出紀錄、法律主題導讀、官方來源、兩次死亡日期、適用版本待核實、不確定事項、其他安排的可能性，以及重新挑戰。法律細節自願展開，不強制讀完教材。

## 正式版本的「合法安排」分支（本次未啟用）

- W1：父親就自己可處分的財產完成特定形式的遺囑；需具體文件、能力、形式、法規版本及 approved 效力規則。
- W2：母親獨立作出自己的遺囑安排；不能用父親的遺囑處分母親資產，也不能保證母親同意。
- P1：父親或其他合法要保人完成合約與受益人安排，需真實可用的契約事實、有效條款、承保狀態及 approved 規則；不能用「諮詢」取代契約成立。
- F1：父親死亡後建立單一遺產事件；先釐清夫妻財產、債務、繼承人與有效安排，再談分割；原型停在待核實。
- M1：母親死亡後建立另一事件，接續當時實際權利鏈；不得把兩間房再共同分一次。
- R1：兄妹可能提出特留分或其他主張；有效性、期間、對象、範圍與裁判均由獨立法律規則／人工事實審查處理。
- P2：特定有效保單如符合經驗證條件才進入理賠與稅務分支；款項是否取得、何時取得、如何課稅均不得先假定。

這些正式分支已有接口與發布前置條件，**沒有在原型中冒充已依法完成**。本輪可完成的只有敘事後果，不是這些法律效果。
