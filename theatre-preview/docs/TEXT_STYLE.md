# 視覺小說字幕文字風格（zh-TW）

本規範適用目前及後續所有視覺小說的角色台詞、劇情旁白與敘事回顧。

1. 每段字幕末尾不加中文句號「。」；若句號位於段尾引號之內，例如「回家吃飯。」，呈現為「回家吃飯」。
2. 保留問號「？」、驚嘆號「！」及刪節號「……」。不可為了省略句號而移除情緒標點。
3. 句中標點按語意保留，例如「等等。你們已經談好了？」中的句中句號不移除；逗號、頓號、分號及冒號也不一律刪除。
4. 不改動台詞內容、語序、情緒或原意；全部使用台灣繁體中文及台灣慣用語。
5. 法律知識手冊、正式法條引用、法律與稅務解說、系統提示、操作說明及其他正式文件不適用本規範，保留必要句號。
6. 未來新增字幕在撰稿時直接遵守；既有字幕透過共用 `subtitleText()` 僅處理呈現，不改原始劇本、存檔、已讀識別鍵或法律資料。
7. 同一段的字幕、打字呈現、全文閱讀、無障礙文字及對話回顧必須一致。不要對全頁DOM、所有中文字串或法源資料做全域替換。
8. 歷史截圖、影片、封存的改版前對照及正式企劃文件不回溯改寫；新製劇情沿用本標準。

## 例子

- `家安，回來就吃飯，手機先放下。` → `家安，回來就吃飯，手機先放下`
- `「這兩間房，以後都是你們的靠山。」` → `「這兩間房，以後都是你們的靠山」`
- `哥，我以為……` → 保留
- `等等。你們已經談好了？` → 保留
- 系統提示 `尚無已讀對話。` → 保留
- 法律文件引文 → 逐字保留，不套字幕格式函式
