# 指定電影式UI參考・獨立演出介面更新

2026-10-27。使用者已確認本輪附圖為正式介面設計參考；這是UI方向確認，不是人物／場景正式美術簽核，也不是同意整合第一卷。

## 本輪變更
- 一般對話：低干擾半透明深藍字幕、藍色姓名／角色標籤及「點擊繼續」；移除常駐鏡頭除錯標籤，讓場景成為主角。
- 場景背景延伸到字幕後方，人物依頂部功能列與字幕安全區構圖；字幕不遮住說話者的臉，不以縮小字級塞進畫面。
- 重要抉擇：與字幕互斥、背景暗化、獨立選項區，A/B/C深藍方案。只有已選項目使用金色邊光／光暈；未選項目、懸停、字級按鈕及確認按鈕不使用金色光效。
- 未選方案先顯示標題，選取後展開原有完整說明。選取不提交，確認後才推進；可以先逐一查看。沒有刪除既有決策說明。
- 功能列：自動／暫停、對話回顧、選單。手機隱藏文字與次要回顧入口，回顧可由選單開啟；極窄手機將進度移至選單，保留主要操作。
- 功能選單：自動播放、已顯示對話回顧、100/125/150%、減少動態、重播與必要法律／素材資訊。選單／回顧開啟即暫停，關閉不自動偷跑；明確按播放才恢復。
- 回顧只在本頁記憶體記錄實際顯示的台詞，未讀及未選分支不出現；刷新或重播會清除。沒有新增存檔格式、帳號或持久化系統。

## 保護範圍
SCENE、OPTIONS、Transport、人物／表情／背景素材不變。renderer只增加字幕／頂列安全區參數及前景裁切；沒有重製人物、改變情緒時間或劇情。

正式經營模式、第一卷六次選擇及八結局、State v4、法律效果及既有林家安局部動畫樣機未修改。原新場景的全部PNG/WebP仍與assets.json相同。一般對話與重要抉擇不會同時顯示。
