素材完成狀態：請勿誤認為正式 2.5D

已完成的是原創 SVG 分層向量佔位稿，不是精緻正式 2.5D 立繪。 不把原本整張概念立繪硬貼嘴巴，不用六張長相不同的生成圖冒充同一人。它的用途是確認構圖、表情辨識與動態節奏。正式美術品質仍需使用者確認及美術製作。

- 身體、臉型、髮型、服裝、膚色、光影使用同一組固定幾何與漸層。

- 六種表情只改眼眉、嘴角的向量路徑及瞳孔位置；同一角色不重新生成整張臉。

- 眨眼為眼睛收合／閉眼線，呼吸為 3px 位移與 0.6% 縮放；頭部約 0.3 度擺動。這不是肌肉或軀幹網格變形。

- 嘴型是閉合與一個開口層的幅度變化，配合文字顯示啟停；不是錄音、聲音辨識、音素對嘴或配音完成品。

- 進退場及走位是整體平移，沒有手臂動作、指向文件或拿起物品的正式姿勢。

- 背景沿用既有原創台灣客廳概念圖。人物與背景精緻度不同，明確保留佔位標記，不宣稱畫風已定稿。

正式美術交付規格

1. 每角一份已核准角色設定：三視圖／臉部特徵、年齡、服裝、比例、主色、光源；先定稿平靜表情，再製作同臉表情。

2. 建議母檔至少 1600×2400 透明背景 PSD／相容分層格式，固定腳底／眼睛／頸部註冊座標，不在不同表情重新裁切。保留可重複輸出的 SVG 或 PNG／WebP。

3. 分層：後髮、身體、服裝、頸、臉、左右眼白／虹膜／眼皮、左右眉、鼻、閉口／微張／張口、前髮、配件；呼吸所需遮擋區域補畫，不留透明裂縫。

4. 六表情對照表及疊圖驗收：瞳距、鼻、輪廓、髮線、衣領、光源一致。只允許表情相關部位與明確核准的姿態變化。

5. 手機首屏只載入當場素材；建議單角目標 250–600KiB，實際依美術畫質驗收，不把此數字當成已達成的正式素材結果。

6. 著作權／商用授權／來源與工具紀錄、第三方素材清單、修改權、再散布範圍、審核人與版本必須附檔。本輪向量佔位稿為專案新寫的程式幾何，沒有競品角色、商標或 UI 圖檔。

可重用結構

- scene.mjs：資料化分鏡（人物、表情、位置、鏡頭、光影、時長）、表情清單、三種測試回應；不匯入 story.mjs。

- rig.mjs：固定角色幾何＋六種表情圖層，提供 createRig、setExpression。日後可改為正式分層素材 renderer，不變更故事引擎。

- clock.mjs：單一可暫停時鐘，保留剩餘時間，隱藏頁面不追趕事件。

- app.mjs：閱讀、設定、回顧、手動／主動播放、焦點與演出調度。

- stage.css：CSS 動態、手機／平板／桌面構圖，動態與字幕互不綁定；字幕始終不參與鏡頭與震動。

效能與可及性邊界

使用 CSS 動畫與單一文字 timeout／單一分鏡 timeout；沒有永久 JS requestAnimationFrame 迴圈，沒有 Canvas／Phaser／React／WebGL 額外載入。三名角色只在本場保留，背景是既有壓縮 WebP。不新增外部字型請求。

關閉動態後停止眨眼、呼吸、嘴型、鏡頭轉場、震動與連續色光變化；仍保留靜態表情及可閱讀選項。系統減少動態會同時取消逐字效果。不是單純降低動畫速度。背景分頁暫停計時與文字，不補跑。

字幕桌面 23px、手機／平板 21px，隨文字設定放大。次要說明不低於 18px；小型素材標記為 15–16px 基準。操作目標至少 48px。視窗不足時在閱讀面板或設定面板內捲動；不是把所有字縮小。

自動演出是玩家明確選擇的示範，不用於強迫閱讀或新手教學。未使用聲音、閃爍、全螢幕白光。暫停後不自行恢復；按鈕可操作，不需要鍵盤快捷鍵。空白鍵只在焦點為頁面時繼續，不攔截表單或按鈕。
