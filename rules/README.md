# 維護者法律規則草稿

registry.json 是第一批供維護者審查的 JSON 規格，不是已啟用規則庫。12筆版本記錄（其中民法1223有兩個版本線索），7個模組，全部 draft；approved 數量為0。

2026遺產稅四項金額與三級距原樣收錄使用者提供內容及財政部公告URL，尚非完整稅額公式。1223修法線索不推定施行日，effective_from仍為null。其他模組只是欄位／來源線索，未核實的法律效果不啟用。

本輪未完成的選版、CLI審核與計算測試原型已隔離到 prototypes。規則JSON未接入遊戲計算，也不應把內含的test_cases視為已通過的法律測試。現有遊戲仍使用原先的法律未驗證閘門。
